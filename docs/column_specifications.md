# 希腊叠塔游戏 - 柱式规范文档

本文档详细说明希腊叠塔游戏中各种柱式的技术规格、设计要求和实现标准，作为3D建模和集成开发的依据。

## 总体设计原则

根据希腊建筑传统，我们将实现三种经典柱式，分别用于不同高度的塔层（层数只是游戏进度百分比参考，后面会通过实际测验来改动）：

1. **科林斯柱式**（Corinthian）：最华丽复杂的柱式，用于塔的底部（1-3层）
2. **爱奥尼克柱式**（Ionic）：中等复杂度的柱式，用于塔的中部（4-6层）
3. **多立克柱式**（Doric）：最简洁的柱式，用于塔的上部（7层以上）

每种柱式都将保持希腊建筑的比例和特征，同时确保在游戏环境中有良好的性能表现。

## 罗马柱堆叠切削系统设计

### 概述

本模块基于传统方块堆叠游戏的核心机制，升级为"罗马柱建造"逻辑。通过不断削减滑入方块的横向对齐部分，最终使柱体逐步细化、升高，并在美术上表现出古典柱式的美感与结构。

目标是：将每次对齐变为一次建造艺术，使"削弱"成为"雕刻"的过程。

### 初始模型结构

每一块滑入的方块为长方体，具有如下标准尺寸比例：
- 宽度（X）：1
- 高度（Y）：1
- 深度（Z）：1.5

顶视图和正视图均为正方形，具备强烈的"实体感"与"视觉权重"。所有堆叠结构基于该模型尺寸的缩放变体。

### 相机视角

固定为斜角透视视图（isometric-like），玩家可同时观察：
- 上表面
- 前侧立面
- 右侧或左侧侧面

该视角强调纵深感、建筑体量感，有助于增强堆叠仪式感。

### 滑块运动与判定

- 滑入方块沿对角线方向（X+/Z-）移动
- 每次下落前，判定其与下方已有结构的 X/Z 平面重叠区域
- 若有偏移，则进行"切削"操作：
  - 保留重叠区域作为主块，继续堆叠
  - 分离偏移区域作为"碎块"，下落并淡出

### 切削与变形逻辑

#### 保留部分：
- 仅保留与下方结构在 X/Z 平面的重合区域
- 保持高度（Y）恒定不变
- 将保留部分位置重心对齐并替代原方块

#### 被切部分：
- 计算超出区域尺寸
- 创建一个新的 mesh 作为"碎块"
- 执行下落动画、淡出动画，或物理引擎自由落体处理

### 罗马柱演进机制

每一次切削使得主块在横向逐渐变窄（X/Z方向），最终演化为一个"高耸细柱"。

可设置一个阈值（如 X 或 Z 缩至 0.3 以下）时：
- 自动替换为预设"柱身"模型或高光材质，代表"完成一段柱形"
- 或加入"柱头""柱础"以构成完整建筑部件

整体效果呈现"逐层雕刻 → 柱式升高"的美术演出。

## 方块尺寸与比例变化

通过对参考图片的分析，发现方块的尺寸比例随着塔的高度有明显变化，这种变化是由切削系统自然产生的：

### 底部层（科林斯柱式）
- **比例特征**：明显的扁平长方形，宽度大于高度
- **尺寸比例**：约为1:1:1.5（宽:深:高）
- **实际效果**：宽大稳固的基座，体现基础的稳定性
- **视觉感受**：横向延展，显得庄重厚实
- **切削原理**：初始几层的切削较少，保留了更多的原始宽度

### 中间层（爱奥尼克柱式）
- **比例特征**：接近正方体，但略显扁平
- **尺寸比例**：约为1:1:1.5（宽:深:高）
- **实际效果**：随着切削逐渐变得紧凑
- **视觉感受**：平衡的几何形态，过渡自然
- **切削原理**：随着层数增加，水平误差累积导致宽度逐渐减少

### 上部层（多立克柱式）
- **比例特征**：高挑的长方体，高度大于宽度
- **尺寸比例**：约为1:1:1.5（宽:深:高）
- **实际效果**：由于不断切削，剩余部分显得越来越窄高
- **视觉感受**：向上延伸，体现塔的攀升感
- **切削原理**：当X或Z方向尺寸小于阈值时，可能触发特殊的柱式效果

### 比例变化技术实现
- **计算公式**：新方块尺寸 = 上一层方块尺寸 × 重叠比例因子
- **重叠计算**：使用 AABB（轴对齐边界框）碰撞检测来确定重叠区域
- **切削精度**：可设置精度参数，允许一定的偏差容忍度（如±0.05单位）
- **阈值触发**：当某一维度小于阈值（如原始尺寸的30%）时，可触发特殊的视觉效果或模型替换

## 通用技术规格

所有柱式模型需遵循以下通用技术规格：

### 模型技术要求

- **文件格式**：.glb（推荐）或.obj（备选）
- **多边形数量**：
  - 科林斯柱式：最多2000三角形
  - 爱奥尼克柱式：最多1500三角形
  - 多立克柱式：最多1000三角形
- **UV映射**：单一UV映射，512×512分辨率，合理布局避免拉伸
- **纹理尺寸**：512×512像素，PNG格式（带透明通道）
- **LOD级别**：至少提供2级LOD，用于远距离简化细节
- **碰撞体**：为每个模型提供简化的碰撞盒或碰撞体，以优化物理计算

### 材质参数

- **基础材质**：大理石质感，适中的粗糙度（0.7-0.8）
- **金属度**：低（0.05-0.1），模拟石材的微光泽
- **反照率**：大理石白为基础（#F5F5F5），可有轻微的纹理变化
- **法线贴图**：提供适当的表面细节，体现石材纹理和年代痕迹
- **环境光遮蔽**：增强凹槽和细节的深度感

## 科林斯柱式（底部1-3层）

科林斯柱式是最华丽的希腊柱式，特点是装饰繁复的柱头，适用于塔的底部层，体现基础的稳固和华丽。

### 设计特征

- **柱基**：宽大的方形或圆形基座，带有多层阶梯状过渡
- **柱身**：相对扁平但宽度大的圆柱体，表面有浅纵向沟槽（24条沟槽）
- **柱头**：最具特色部分，装饰有橡叶和金合欢叶的复杂花篮式设计
- **装饰细节**：柱头有螺旋卷草纹和叶片装饰，立体感强
- **比例适应**：设计时需适应2:1:0.5的扁平比例，强调横向延展感

### 颜色规格

- **基础色**：大理石白（#F5F5F5）
- **装饰色**：适量使用赭石黄（#D4B16A）点缀柱头的叶片装饰
- **阴影色**：使用淡灰色（#D1CEC7）增强浮雕效果
- **纹理变化**：轻微的大理石纹理，纹理对比度控制在20%以内

### 多边形分布建议

- **柱基**：约500三角形
- **柱身**：约500三角形
- **柱头**：约1000三角形（重点细节区域）

### 特殊效果

- **完美叠放**：叠放完美时，柱头的装饰部分可有轻微的金色发光效果
- **切割效果**：如被切割，断面应有合理的内部纹理
- **碎块效果**：切削产生的碎块应保持相同的材质和质感，但可略微降低细节

## 爱奥尼克柱式（中部4-6层）

爱奥尼克柱式特点是优雅的涡卷形柱头，适用于塔的中部层。

### 设计特征

- **柱基**：比例适中的圆形或方形基座，带有简单的过渡环
- **柱身**：近似正方形比例的圆柱体，表面有较深的纵向沟槽（20条沟槽）
- **柱头**：两侧有典型的双涡卷装饰，中间连接有装饰带
- **装饰细节**：柱头涡卷精致但不过于复杂，保持清晰的轮廓
- **比例适应**：设计时需适应1.5:1:0.8的过渡比例，体现从扁平向垂直的转变

### 颜色规格

- **基础色**：大理石白（#F5F5F5）略带米色（#E8E6E1）
- **装饰色**：涡卷边缘可使用淡赭石黄（#E6CFA3）提升层次感
- **阴影色**：使用淡灰色（#D1CEC7）增强沟槽和涡卷的立体感
- **纹理变化**：中等大理石纹理，纹理对比度控制在15%以内

### 多边形分布建议

- **柱基**：约300三角形
- **柱身**：约600三角形
- **柱头**：约600三角形

### 特殊效果

- **完美叠放**：叠放完美时，涡卷部分可有轻微的蓝色波纹效果
- **切割效果**：断面应显示适当的磨损和风化细节
- **碎块轨迹**：中部层的碎块可有更明显的旋转效果，体现过渡的动态性

## 多立克柱式（上部7层以上）

多立克柱式是最简洁的希腊柱式，特点是简单直接的设计，适用于塔的上部层。

### 设计特征

- **柱基**：简单的小型圆盘或方形基座，几乎没有装饰
- **柱身**：细长的圆柱体，表面有浅沟槽（16-20条沟槽）
- **柱头**：简单的方形或圆形顶板，下方有简洁的过渡环
- **装饰细节**：几乎没有复杂装饰，以简洁的几何形态为主
- **比例适应**：设计时需适应1:1:1.5的垂直比例，强调向上延伸感

### 颜色规格

- **基础色**：纯净的大理石白（#F5F5F5）
- **装饰色**：极少量使用，主要依靠光影变化产生层次
- **阴影色**：使用淡灰色（#D1CEC7）增强简单的立体感
- **纹理变化**：轻微的大理石纹理，纹理对比度控制在10%以内

### 多边形分布建议

- **柱基**：约200三角形
- **柱身**：约500三角形
- **柱头**：约300三角形

### 特殊效果

- **完美叠放**：叠放完美时整体有轻微的白色光晕效果
- **切割效果**：断面应显示清晰的几何形态
- **碎块效果**：上部层的碎块可能较小，但应有轻微的粉尘效果增强视觉反馈

## 技术集成要点

### 变形系统

方块在成功叠放后应从初始的立方体平滑变形为对应的柱式，需要考虑不同高度层的比例变化：

1. **变形时间**：约0.5-0.8秒
2. **变形曲线**：建议使用Elastic.easeOut缓动函数，产生轻微的弹性感
3. **中间状态**：变形过程中应保持模型的完整性，避免严重的穿模现象
4. **比例适应**：变形系统需根据塔的高度动态调整变形目标的比例，确保视觉连贯性

### 切削系统实现

1. **重叠检测**：
   - 使用射线投射法确定方块在X/Z平面上的重叠区域
   - 计算重叠百分比（重叠面积/原始面积）
   - 根据重叠百分比计算得分或效果触发

2. **分割处理**：
   - 计算非重叠部分的几何信息
   - 动态生成新的网格表示切割碎片
   - 为碎片应用物理属性（重力、阻尼等）

3. **变形触发**：
   - 当尺寸比例达到特定阈值时触发模型替换
   - 科林斯柱式：宽度>1.8时触发
   - 爱奥尼克柱式：宽度介于1.2-1.8之间触发
   - 多立克柱式：宽度<1.2时触发

4. **性能优化**：
   - 使用对象池管理碎片实例
   - 设置最大同时存在的碎片数量
   - 超过阈值的旧碎片直接销毁而非动画消失

### 动态LOD

根据摄像机距离和场景复杂度，动态调整模型细节：

1. **近距离**：使用完整模型
2. **中距离**：使用简化的第一级LOD（约减少30%三角形）
3. **远距离**：使用最简化的第二级LOD（约减少60%三角形）

### 纹理优化

为提高性能和减少内存占用：

1. **合并贴图**：考虑将三种柱式的纹理合并为一张图集
2. **压缩格式**：使用WebGL支持的压缩纹理格式
3. **MIP映射**：确保启用MIP映射以优化远距离渲染

## 总结

本规范文档提供了希腊叠塔游戏中的柱式堆叠切削系统的详细技术规格和设计要求。通过精心设计的切削机制，游戏可以实现方块从底部扁平到顶部细长的自然变化，形成从科林斯、爱奥尼克到多立克柱式的渐进演变。这种变化不仅符合古典建筑的美学原则，也创造了独特的游戏体验。

**注意**：虽然方块比例有变化，但在游戏机制中，这种变化很可能是由切削效应自然产生的，而非需要为每个高度层创建完全不同的模型。建模时应确保模型能够适应这种视觉效果，同时保持叠放逻辑的合理性。

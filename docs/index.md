## 🔍 使用指南

### 如何使用这些文档

1. **新成员入职** - 从计划中的[项目概述](project_overview.md)开始，了解项目的基本情况
2. **设计参考** - 使用设计文档作为美术和开发的规范依据
3. **进度跟踪** - 通过进度文档了解当前开发状态和接下来的任务
4. **技术实现** - 参考技术文档中的实现细节和算法说明
5. **开发计划** - 参考[渐进式改造计划](development_plan.md)了解开发步骤和优先级
6. **视觉设计** - 遵循[希腊风格设计指南](greek_style_guide.md)确保视觉风格一致
7. **功能实现** - 实现新功能时参考相应的功能设计文档，如[Oracle预言系统设计](oracle_system_design.md)

### 文档更新流程

1. 重大设计变更需在相应文档中更新并在更新日志中记录
2. 完成的任务需在进度文档中标记并更新相应状态
3. 新增功能或系统需添加相应的技术文档或设计说明
4. 文档从"计划中"移动到"已完成"状态时，更新本索引

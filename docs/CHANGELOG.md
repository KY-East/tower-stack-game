# 希腊叠塔游戏 - 更新日志

本文档记录希腊叠塔游戏开发过程中的所有重要变更。

- 创建了柱式规范文档，详细定义了三种希腊柱式（科林斯、爱奥尼克、多立克）的技术规格和设计要求
- 整合了罗马柱堆叠切削系统设计方案，提供了详细的切削机制技术实现思路

  - 移动系统优化（渐进式减速、动态范围）
  - 堆叠判定系统改进（2%误差自动对齐、双级判定）
  - 反馈系统增强（视觉和音频反馈）
  - 难度平衡设计（缓慢减速、动态微调）

### 改进
- 设计修改：柱式顺序颠倒，复杂柱式（科林斯柱式）放在底部，简单柱式（多立克柱式）放在上部
- 游戏体验：设计了更平衡的游戏体验方案，需通过实际测试确定具体参数
- 性能优化：提出了根据游戏测试结果调整游戏整体节奏的方向
- 技术细化：明确了方块比例随高度变化的技术原理，确定了切削系统的具体实现方式
- 建模规范：提供了详细的3D模型技术规格，包括多边形数量、材质参数和LOD要求
- 颜色系统：简化了希腊风格的颜色方案，仅保留4种主要颜色（大理石白、赭石黄、橄榄绿、陶器红），并移除了与背景相近的蓝色，根据方块高度层级动态选择不同颜色集合
- 材质升级：从基础材质升级到高级材质(MeshPhongMaterial)，添加高光、粗糙度等细节，实现基于高度的材质质感变化；同时添加阴影系统，提升整体视觉效果
- 游戏体验优化：修改了游戏体验设计文档中的关键机制
  - 将移动速度从线性增加改为缓慢减少（每层减少2%）
  - 将容错机制从5%改为2%，更注重精确性
  - 简化判定等级为两级（完美/一般）
  - 移除了辅助线功能，保持游戏核心体验
  - 保留打击感设计框架，待后续详细设计
- 相机系统优化：改进了相机跟随逻辑
  - 保持相机固定视角和位置，确保游戏视角的一致性
  - 优化相机移动时机，从第4个方块开始才触发相机上移
  - 相机移动距离基于超出3个方块后的累积高度计算
  - 移除了之前的即时跟随逻辑，改为更自然的渐进式移动
- 速度系统优化：简化了方块移动速度机制
  - 移除了加速度系统，改为固定速度移动
  - 设置合适的固定速度（0.3）
  - 移除了最大速度限制（不再需要）
  - 简化了tick方法中的速度计算逻辑
- 方块移动范围优化：调整了方块的移动范围以适应新的尺寸
  - 将移动范围从12增加到45（比方块宽度30更大）
  - 确保方块出现时就有足够远的初始距离
  - 增加了游戏的挑战性，需要更精确的时机判断
- 方块切割系统优化：添加了最小尺寸限制
  - 设置最小允许尺寸为10单位（原始尺寸的1/3）
  - 保持了合理的柱子比例（10:15 ≈ 1:1.5）
  - 确保视觉效果的清晰度
  - 当切割后尺寸小于最小值时结束游戏

### 游戏核心机制优化

#### 判定系统升级
- 新增双层判定机制：
  - Perfect判定（≥95%重叠）：保持完整方块，不切割
  - Good判定（≥93%重叠）：保持原有切割逻辑
- Perfect判定时方块完整保留，直接堆叠
- 优化判定显示效果：
  - Perfect: 金色"✨ PERFECT! ✨"，带弹出和持续发光动画
  - Good: 绿色"⭐ GOOD! ⭐"，带滑入动画
  - 使用游戏风格字体（Press Start 2P, Orbitron）
  - 添加动态文字效果和发光效果

#### 音效系统
- 添加关键音效：
  - Perfect判定音效（perfectDing.mp3，音量0.8）
  - 游戏结束音效（failur.mp3，音量0.5）
- 在以下情况触发音效：
  - Perfect判定时播放叮声
  - 游戏结束时播放失败音效

#### 视觉反馈优化
- 添加动画效果：
  - Perfect: 弹出动画 + 持续发光
  - Good: 从上方滑入 + 弹性效果
- 优化文字显示：
  - 不同大小的字体（Perfect: 52px, Good: 46px）
  - 差异化的显示时间（Perfect: 1.5s, Good: 1.2s）
  - 添加装饰性符号（✨, ⭐）

### 技术改进

## [2024-03-xx] 奖励系统更新

### Added
- 添加连击奖励系统
  - Perfect连击奖励：
    - 连续3次 → 2倍分数（2分）
    - 连续5次 → 3倍分数（3分）
    - 连续10次 → 5倍分数（5分）
  - Perfect总数奖励：
    - 每累计20次Perfect → 总分翻倍
  - 基础得分：
    - Perfect：1分（可与连击倍率叠加）
    - Good/其他情况：1分（重置连击）

### Technical Details
- 在`Game`类中实现连击计数和倍率系统
- 使用`perfectStreak`跟踪当前连击数
- 使用`totalPerfectCount`跟踪Perfect总数
- 使用`scoreMultiplier`管理总分倍率

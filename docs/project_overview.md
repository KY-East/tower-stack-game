# 希腊叠塔游戏 - 项目概述

## 项目背景

希腊叠塔游戏是一个以古希腊建筑为主题的3D堆叠游戏。玩家需要通过精准的时机控制来叠放移动中的方块，建造尽可能高的塔。游戏采用Three.js进行3D渲染，提供流畅的游戏体验和视觉效果。

## 项目目标

本项目旨在对现有叠塔游戏进行希腊风格的改造，主要目标包括：

1. 提升游戏的视觉表现，融入希腊建筑元素和风格
2. 增强游戏的反馈系统，为玩家提供更好的操作感受
3. 添加预言系统(Oracle)，增加游戏的深度和故事性
4. 将游戏界面文本改为英文，提高国际化程度
5. 优化性能和兼容性，确保在各种设备上流畅运行

## 核心玩法

游戏的核心玩法保持不变：

1. 玩家通过点击屏幕或按空格键放置移动中的方块
2. 方块精准放置在下方方块上可继续堆叠
3. 如果方块悬空部分过大，将被切割并掉落
4. 随着塔高增加，方块移动速度加快，难度增加
5. 游戏目标是尽可能堆叠更多方块，建造更高的塔

## 主要改进方向

与原版游戏相比，改进的主要方向包括：

1. **视觉风格**：引入希腊建筑和艺术元素，使用大理石纹理和希腊色彩方案
2. **判定系统**：简化为"完美"和"一般"两种判定，提供差异化的视觉反馈
3. **预言系统**：在关键游戏节点显示神秘预言，增加游戏深度
4. **反馈系统**：为不同的游戏事件提供更加丰富的视觉和听觉反馈
5. **界面改进**：设计符合古希腊风格的UI界面，提升整体美感

## 技术栈

- **前端框架**：原生JavaScript
- **3D渲染**：Three.js
- **构建工具**：Browserify + Budo
- **动画库**：TweenLite
- **音频处理**：Web Audio API

# 希腊叠塔游戏 - 方块设计文档

本文档详细说明希腊叠塔游戏中方块的设计原则、变形机制和分步骤实施计划，为开发团队提供明确的指导。

## 设计原则

希腊叠塔游戏的方块设计遵循以下核心原则：

1. **形态转变**：方块从简单立方体到希腊建筑元素的视觉转变
2. **叠放反馈**：通过视觉效果反映叠放的准确性
3. **渐进简化**：随着高度增加，柱式装饰从复杂到简洁，适应不同空间展示需求
4. **希腊风格**：贯彻古希腊建筑元素和装饰风格
5. **游戏体验平衡**：提供适当挑战性的同时保持良好的游戏体验
6. **性能优化**：确保视觉效果不影响游戏性能

## 核心机制：方块变形

游戏的方块设计核心在于其**变形机制**：

1. **初始状态**：方块以普通几何立方体形式出现并移动
2. **叠放后**：方块被成功叠放并切割后，变形为希腊风格柱子
3. **变形时机**：变形发生在方块成功叠放并完成切割的瞬间
4. **掉落部分**：切割掉落的部分保持原始立方体形态，但添加碎裂效果

这一机制确保了游戏玩法的简单性（叠放方块）与视觉表现的丰富性（希腊建筑）的平衡。

## 柱式风格进阶

希腊建筑有三种典型柱式，我们将根据塔的高度应用不同的柱式，但调整顺序使复杂柱式出现在塔的下部：

1. **科林斯柱式**（1-3层）
   - 特点：华丽繁复，装饰丰富，柱顶有橡树叶和金合欢叶
   - 颜色：包含更多金色和陶器红
   - 装饰：复杂的浮雕和图案
   - 原理：作为塔的基础部分，有更多空间展示细节，玩家也有更多时间欣赏

2. **爱奥尼克柱式**（4-6层）
   - 特点：优雅平衡，有基座，柱顶有涡卷装饰
   - 颜色：融入赭石黄和希腊蓝
   - 装饰：添加回纹图案和简单浮雕
   - 原理：中等复杂度，作为过渡层次

3. **多立克柱式**（7层以上）
   - 特点：简洁朴素，无基座，直纹柱身
   - 颜色：以大理石白为主
   - 装饰：最少的简单纹路
   - 原理：在塔的上部使用简洁设计，适应有限空间并减轻视觉负担

## 游戏体验调整方向

游戏当前难度较高（测试中最多只能叠到6-10层），为了提升游戏体验，我们将考虑以下调整方向：

1. **游戏节奏**：
   - 需要通过实际测试找到最佳的整体游戏速度
   - 方块移动和游戏节奏的调整需要在保持挑战性的同时提高可玩性

2. **打击感增强**：
   - 探索视觉和听觉反馈的有效方式
   - 需要进行多轮测试找到最佳的反馈机制
   - 打击感的设计不应分散玩家注意力

3. **游戏平衡**：
   - 在挑战性和可玩性之间找到平衡点
   - 通过测试确定合理的偏差容错范围
   - 整体游戏节奏应该流畅且有节奏感

## 特殊效果

根据叠放精准度，方块将展现不同的特殊效果：

1. **完美叠放**（偏差较小）
   - 金色光芒从接触面向外扩散
   - 柱式细节增强，添加金色元素
   - 适当的摄像机震动和光晕效果
   - 粒子效果：金色星尘
   - 明显的音效反馈

2. **良好叠放**（偏差中等）
   - 蓝色波纹效果
   - 正常柱式变形
   - 轻微的摄像机反馈
   - 粒子效果：蓝色尘埃
   - 基础音效反馈

3. **一般叠放**（偏差较大）
   - 无特殊光效
   - 基础柱式变形
   - 无摄像机反馈
   - 粒子效果：简单的尘土
   - 最小音效反馈

## 颜色方案

方块将使用以下希腊风格色彩方案：

- **希腊蓝** `#1A75BB` - 代表爱琴海和天空
- **大理石白** `#F5F5F5` - 代表神庙和雕塑
- **赭石黄** `#D4B16A` - 代表古老卷轴和沙地
- **橄榄绿** `#708D23` - 代表橄榄树和自然环境
- **陶器红** `#B64534` - 代表希腊陶器

颜色选择不再完全随机，而是根据以下原则：
1. 底层使用更多陶器红、赭石黄和金色元素
2. 中层主要使用赭石黄、橄榄绿和希腊蓝
3. 上层主要使用大理石白和希腊蓝，色彩简洁明亮

## 分步实施计划

为了确保渐进式改造顺利进行，方块设计将按以下步骤实施：

### 步骤1：颜色系统改造和游戏体验调整
- **工作内容**：
  - 修改颜色生成机制，使用预定义的希腊风格色彩方案
  - 实现基础的颜色渐变，随高度变化颜色
  - 调整材质参数，使颜色更加鲜明
  - 通过测试找到合适的游戏节奏参数
  - 建立基础的反馈系统框架
- **涉及文件**：
  - `src/config.js`：添加希腊风格色彩配置和游戏体验参数
  - `src/block.js`：修改颜色选择逻辑
  - `src/game.js`：调整游戏体验参数

### 步骤2：基础变形机制和反馈系统
- **工作内容**：
  - 实现方块叠放后的基础形状变形（从方块到简单柱子）
  - 添加叠放效果和切割效果
  - 改进材质，添加基础纹理
  - 建立基础的反馈机制
- **涉及文件**：
  - `src/block.js`：修改方块生成和变形逻辑
  - `src/game.js`：调整叠放判定和反馈触发
  - 新建`src/feedback.js`：实现反馈系统

### 步骤3：柱式风格实现
- **工作内容**：
  - 实现三种柱式的具体几何形状
  - 根据高度选择不同柱式（复杂到简单）
  - 添加柱式特有的装饰元素
- **涉及文件**：
  - `src/block.js`：添加柱式生成函数
  - 新建`src/column_styles.js`：定义不同柱式的几何参数

### 步骤4：特效与反馈增强
- **工作内容**：
  - 添加基于叠放精准度的特效系统
  - 实现粒子效果、光效和摄像机反馈
  - 优化性能，确保流畅运行
- **涉及文件**：
  - `src/game.js`：精准度判定和特效触发
  - 新建`src/effects.js`：特效系统实现

## 注意事项

1. **性能考虑**：
   - 复杂几何体可能影响性能，应使用LOD（细节级别）技术
   - 粒子效果数量应有上限，避免过多粒子同时存在
   - 考虑使用实例化渲染优化多个类似柱子的渲染

2. **游戏性平衡**：
   - 视觉效果应增强游戏反馈，但不应干扰游戏体验
   - 游戏难度应通过反复测试调整，寻找最佳平衡点
   - 保持视觉清晰度，即使在复杂装饰下也不影响判断

3. **渐进实施**：
   - 每个步骤完成后进行充分测试，确保可玩性
   - 随时准备回滚有问题的改动
   - 优先实现基础功能和游戏体验改进，再添加复杂特效

# 希腊叠塔游戏 - 希腊风格设计指南

本文档提供希腊叠塔游戏的视觉设计指南，包括色彩方案、风格元素和设计原则，确保游戏的视觉表现具有一致的希腊风格。

## 色彩方案

### 主色调

游戏使用以下主要色彩建立希腊风格的视觉基调：

- **希腊蓝** `#1A75BB` - 代表爱琴海和天空
- **大理石白** `#F5F5F5` - 代表神庙和雕塑
- **赭石黄** `#D4B16A` - 代表古老卷轴和沙地
- **橄榄绿** `#708D23` - 代表橄榄树和自然环境
- **陶器红** `#B64534` - 代表希腊陶器

### 色彩用途

| 颜色 | 主要用途 |
|------|---------|
| 希腊蓝 | 背景、天空、水元素、UI强调 |
| 大理石白 | 建筑主体、文字、UI背景 |
| 赭石黄 | 装饰元素、沙地、纸卷、强调 |
| 橄榄绿 | 植被、自然元素、次要装饰 |
| 陶器红 | 重要强调、警告、错误提示 |

## 方块设计

### 基本形态

游戏的核心元素是希腊风格的方块，应具有以下特点：

- **建筑元素**：方块设计为希腊建筑元素，如神庙、柱子和台阶
- **材质**：大理石纹理，带有适当的磨损和年代感
- **装饰**：希腊回纹、橄榄枝等装饰图案
- **比例**：遵循古希腊建筑的和谐比例

### 柱式风格

游戏中可以使用三种古希腊柱式，随着游戏进程逐渐演变：

1. **多立克柱式**（Doric）：最简洁朴素的柱式，用于游戏初始阶段
   - 特点：无基座，粗壮，直纹柱身，简单的柱顶
   
2. **爱奥尼克柱式**（Ionic）：较为优雅的柱式，用于中期阶段
   - 特点：有基座，较细，有卷涡形柱顶
   
3. **科林斯柱式**（Corinthian）：最华丽的柱式，用于高级阶段
   - 特点：复杂的基座，细长，带有橡树叶和金合欢叶装饰的柱顶

### 方块层次

随着塔的高度增加，方块设计可以有以下演变：

- **低层（1-5层）**：简单的多立克石块，基础的大理石纹理
- **中层（6-15层）**：爱奥尼克元素，增加回纹装饰
- **高层（16层以上）**：科林斯元素，增加更复杂的装饰和金色点缀

## 界面设计

### 游戏开始界面

- **布局**：神庙前部视角，以多立克柱式为主
- **标题**：大理石质感的游戏标题，置于顶部
- **开始按钮**：设计为石刻浮雕，悬停时发光
- **背景**：淡蓝色天空和远处的山丘剪影

### 游戏界面

- **方块区域**：占据屏幕中央，背景简洁不分散注意力
- **分数显示**：设计为石刻计分板，位于屏幕上方
- **指导文本**：简洁的英文说明，使用古典衬线字体
- **预言文本框**：半透明的云雾效果，文字缓慢显现

### 游戏结束界面

- **结算面板**：设计为大理石石板，显示最终分数
- **装饰**：月桂花环环绕最终分数
- **重新开始按钮**：石刻风格，与开始按钮保持一致
- **背景**：稍微暗淡，突出结算面板

## 字体选择

### 游戏标题

- 字体：`'Trajan Pro'` 或 `'Cinzel'`
- 特点：宽阔有力，类似古罗马石刻字体
- 应用：游戏标题、主要标题

### 界面文本

- 字体：`'Palatino Linotype'` 或 `'Roboto'`
- 特点：清晰易读，带有古典感
- 应用：按钮文本、游戏说明、预言文本

### 分数显示

- 字体：`'Orbitron'` 或 `'Rajdhani'`
- 特点：几何感强，现代风格
- 应用：分数、层数显示

## 视觉效果

### 方块效果

- **完美叠放**：金色光芒从接触面向外扩散，方块短暂发光
- **一般叠放**：蓝色波纹效果，柔和的光效
- **切割效果**：大理石碎裂纹理和粉尘
- **掉落效果**：旋转下落，接触地面时产生尘土

### 环境效果

- **背景云彩**：缓慢移动的白云
- **光线效果**：随高度变化的光线角度和强度
- **粒子效果**：空气中漂浮的微小光点

### 摄像机效果

- **叠放时**：轻微的摄像机震动
- **完美叠放**：更强的震动和短暂的放大效果
- **高度增加**：摄像机缓慢上移，保持最佳视角

## 响应式设计

游戏界面应适应不同屏幕尺寸：

- **核心区域**：保持固定比例，确保游戏体验一致
- **装饰元素**：可根据屏幕大小适当缩放或隐藏
- **触控适配**：确保按钮和交互元素足够大，适合触控操作
- **竖屏模式**：提供优化的竖屏布局，适应移动设备

## 实现建议

1. **渐进式实现**：先实现基础的色彩和纹理，再逐步添加复杂效果
2. **资源优化**：确保纹理和图像经过优化，不影响加载速度
3. **性能考虑**：复杂效果应有降级方案，适应不同性能的设备
4. **一致性**：所有视觉元素应保持风格一致，避免混入不相关的设计元素

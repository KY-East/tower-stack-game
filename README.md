# Greek Tower Stack Game

An immersive tower stacking game inspired by ancient Greek architecture. Test your precision and timing as you build a magnificent Greek temple reaching for the heavens.

## Dependencies

- Node v10.14.2 or higher
- NPM v6.4.1 or higher
- Modern browsers (Chrome/Firefox/Safari/Edge latest version)

## Features

- Challenging precision-based gameplay
- Ancient Greek temple architectural elements
- Dynamic visual feedback system
- Oracle system with mysterious prophecies (coming soon)
- Atmospheric sound effects and music

## Deployment

```bash
# Install dependencies
npm i

# Start development server
npm start

# Open browser and visit
http://localhost:8000
```

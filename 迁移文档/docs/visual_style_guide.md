# 希腊叠塔游戏 - 视觉风格指南

本文档详细说明希腊叠塔游戏的视觉设计风格、核心元素和设计规范，为美术团队提供创作指导。

## 整体风格

希腊叠塔游戏采用现代化的古希腊视觉风格，结合以下特点：

- **古典与现代融合**：保留古希腊建筑和艺术的特征，同时融入现代设计语言
- **几何美学**：强调对称、比例和几何形态
- **明亮清晰**：色彩明快，线条清晰，对比度适中
- **神话氛围**：通过光效、色彩和装饰元素营造神秘而庄严的氛围
- **简洁精致**：保持视觉简洁同时注重精致的细节

## 色彩方案

- **希腊蓝** `#1A75BB` - 代表爱琴海和天空

- **橄榄绿** `#708D23` - 代表橄榄树和自然环境

## 图形元素

### 方块设计

游戏的核心元素是希腊风格的方块，应具有以下特点：

- **建筑形式**：方块设计为希腊建筑元素，如神庙、柱子、房屋等
- **材质表现**：大理石纹理，带有适当的磨损和年代感
- **装饰图案**：希腊回纹、橄榄枝、月桂等点缀在方块上
- **比例协调**：遵循古希腊建筑的黄金比例
- **细节丰富**：适当的阴影、纹理和凹凸细节

![方块设计示例](../assets/images/block_design.png)

### 柱式风格

游戏中的柱子采用三种古希腊柱式：

1. **多立克柱式**（Doric）：简洁朴素，用于基础和低级方块
2. **爱奥尼克柱式**（Ionic）：优雅有旋涡装饰，用于中级方块
3. **科林斯柱式**（Corinthian）：华丽繁复，用于高级和完美方块

![希腊柱式](../assets/images/column_styles.png)

### 装饰图案

统一使用以下装饰图案贯穿游戏界面和元素：

- **回纹图案**（Meander/Greek Key）：用于边框和分隔线
- **棕榈叶纹**（Palmette）：用于装饰角落和重要元素
- **橄榄枝**：象征和平与胜利，用于奖励和成就
- **葡萄藤**：用于点缀和填充装饰
- **波浪纹**：代表爱琴海，用于底部装饰和过渡元素

![装饰图案](../assets/images/decorative_patterns.png)

## 字体与排版

### 字体选择

- **标题字体**：`'Trajan Pro'` 或 `'Cinzel'`
  - 大写，宽阔有力，类似古罗马石刻字体
  - 用于游戏标题、主要标题、重要提示

- **正文字体**：`'Palatino Linotype'` 或 `'Roboto'`
  - 清晰易读，带有古典感
  - 用于游戏内文本、说明、预言文本

- **数字字体**：`'Orbitron'` 或 `'Rajdhani'`
  - 几何感强，现代风格
  - 用于分数、时间、级别显示

### 文本效果

- **神谕文本**：金色描边，淡蓝色辉光，缓慢淡入效果
- **完美叠放**：脉冲光效，字体放大后恢复
- **游戏标题**：大理石纹理填充，轻微阴影
- **分数文本**：数字变化时轻微跳动动画

## 界面设计

### 主界面

- **神庙立面**：游戏主界面设计为希腊神庙前部，多立克柱式支撑着三角形山墙
- **大理石按钮**：所有按钮都是大理石质感，悬停时呈现轻微发光效果
- **古卷菜单**：选项菜单设计为展开的羊皮纸卷轴
- **橄榄枝装饰**：框架和分隔线由橄榄枝图案组成
- **波浪底部**：底部使用爱琴海波浪图案过渡

![主界面设计](../assets/images/main_interface.png)

### 游戏界面

- **神庙背景**：游戏场景背景为雅典卫城风格，有远处的神庙剪影
- **大理石平台**：叠塔的基座是大理石平台，有典型的希腊装饰
- **计分板**：设计为石刻板，数字刻在石头上
- **等级指示**：设计为希腊陶罐，不同等级有不同的花纹
- **预言文本框**：设计为神谕发言的云雾效果，文字缓慢显现

![游戏界面](../assets/images/gameplay_interface.png)

### 结算界面

- **月桂花环**：胜利画面中包含月桂花环环绕最终分数
- **神庙背景**：分数和统计数据显示在神庙立面前
- **大理石奖杯**：根据成绩显示不同等级的奖杯
- **赞美文本**：模仿希腊诗歌的风格赞美玩家的表现

## 动画与特效

### 方块动画

- **叠放动画**：方块叠放时产生轻微的尘土和碎石效果
- **切割动画**：方块切割时显示大理石碎裂纹理和粉尘
- **完美叠放**：金色光芒从接触面向外扩散，柱式细节增强
- **掉落动画**：方块掉落时旋转并产生碎石

### 背景特效

- **云层移动**：背景云层缓慢移动，营造时间流逝感
- **光线变化**：随游戏进程，光线角度和强度变化
- **粒子效果**：空气中漂浮着微小的光点，如同神圣氛围

### 反馈特效

- **音乐触发**：重要动作触发希腊风格的音乐片段
- **震动反馈**：叠放时的摄像机轻微震动
- **失败特效**：方块掉落时的慢动作和褪色效果
- **预言出现**：预言文字伴随神秘的光效和音效

## 响应式设计

游戏界面应适应不同屏幕尺寸，遵循以下原则：

- **保持比例**：核心游戏区域保持固定比例
- **缩放装饰**：装饰元素可根据屏幕大小适当缩放
- **简化版本**：小屏幕上使用简化版的装饰和效果
- **触控优化**：按钮和交互元素足够大，适合触控操作

## 视觉反馈系统

### 叠放评级

| 评级 | 视觉效果 | 颜色 |
|------|---------|------|
| 完美 | 金色光环，柱式升级，光芒四射 | 金色 (#FFD700) |
| 良好 | 蓝色波纹，轻微光效 | 蓝色 (#1A75BB) |
| 一般 | 灰色尘土效果 | 灰色 (#8C8C8C) |
| 不佳 | 红色警示，裂纹纹理 | 红色 (#B64534) |

### 状态指示

- **启动状态**：缓慢旋转的太阳光芒
- **暂停状态**：大理石浮雕风格的暂停图标
- **游戏结束**：破碎的大理石柱和暗淡的光线
- **新纪录**：闪烁的金色月桂花环和光效

## 资产规范

### 纹理分辨率

- **方块纹理**：512×512像素，PNG格式
- **界面元素**：根据尺寸，确保清晰度
- **背景图像**：1920×1080像素，JPEG格式
- **图标**：128×128像素，PNG格式（带透明度）

### 3D模型规范

- **多边形数量**：每个方块保持在2000三角形以内
- **纹理映射**：使用单一UV映射，512×512分辨率
- **材质设置**：使用PBR材质，适当的粗糙度和金属度
- **细节级别**：设置2级LOD，远距离简化细节

## 加载与过渡

- **加载画面**：希腊陶罐上的动画图案
- **关卡过渡**：大理石块叠加构建下一关卡数字
- **菜单过渡**：卷轴展开/收起动画
- **游戏开始**：从顶部飞入的方块，如神灵赐予

## 应用示例

### 方块级别演进

随着游戏级别提升，方块设计逐渐发生变化：

1. **起始级别**：简单的多立克柱式元素，基础大理石纹理
2. **中级阶段**：引入爱奥尼克柱式，增加回纹装饰
3. **高级阶段**：科林斯柱式，增加华丽的雕刻和金色点缀
4. **大师级别**：混合多种元素，增加神话生物浮雕

### 预言系统视觉设计

预言文本的显示采用以下视觉处理：

- **文本框**：半透明的云雾效果，边缘模糊
- **字体**：古典衬线字体，轻微发光
- **出现方式**：文字逐字显现，伴随轻微的蓝光
- **强调词**：关键词使用金色或其他强调色
- **问答式预言**：模拟德尔斐神谕的问答式布局

## 总结

希腊叠塔游戏的视觉风格旨在创造古典与现代结合的独特游戏体验。通过精心设计的色彩、图形、动画和排版，在保持游戏性的同时，营造出沉浸式的古希腊神话氛围。

开发过程中应持续参考本文档，确保视觉元素的一致性、协调性和主题性，同时保持一定的灵活度进行创新设计。

# 希腊叠塔游戏 - Oracle预言系统设计

本文档详细说明希腊叠塔游戏中Oracle预言系统的设计、架构、触发机制和文本内容，为开发团队提供完整的技术规范和创意指导。

## 系统概述

Oracle预言系统是希腊叠塔游戏的核心特色功能，模拟古希腊德尔斐神谕(Oracle at Delphi)向玩家传递神秘预言的体验。该系统在游戏过程中的关键时刻向玩家展示预言文本，增强游戏的沉浸感和神秘氛围。

### 核心功能

- 在游戏关键节点触发预言文本
- 根据玩家表现和游戏状态提供动态内容
- 通过视觉和听觉效果增强预言体验
- 为游戏提供叙事层次和希腊文化元素

## 触发机制

### 基于层数的触发

系统会在特定的塔层数时触发预言，以下是主要触发节点：

| 层数 | 触发条件 | 预言类型 |
|------|---------|---------|
| 1 | 游戏开始 | 欢迎预言 |
| 5 | 首次达到5层 | 鼓励预言 |
| 10 | 首次达到10层 | 赞扬预言 |
| 15 | 首次达到15层 | 挑战预言 |
| 20 | 首次达到20层 | 重要预言 |
| 25 | 首次达到25层 | 转折预言 |
| 30+ | 每5层触发一次 | 高级挑战预言 |
| 最后层数 | 游戏结束 | 总结预言 |

### 基于事件的触发

除了层数触发外，系统还会根据以下游戏事件触发预言：

- **完美叠放**：当玩家实现完美叠放（偏差<1%）时
- **连续成功**：当玩家连续3次成功叠放时
- **濒临失败**：当方块放置偏差>90%但未失败时
- **恢复游戏**：当玩家从暂停状态恢复游戏时
- **新纪录**：当玩家打破个人最高记录时

### 随机触发

为增加游戏的不可预测性，系统还有一定概率在非特定层数随机触发预言：

- 每次成功叠放后有10%的概率触发随机预言
- 随机预言不会连续触发，确保游戏节奏流畅
- 随机预言内容从随机预言池中选取

## 预言内容设计

### 预言类型

系统包含以下几种类型的预言：

1. **引导预言**：向玩家介绍游戏机制和目标
2. **鼓励预言**：在玩家表现良好时提供积极反馈
3. **挑战预言**：增加游戏难度并测试玩家技巧
4. **神秘预言**：提供模糊但引人深思的内容
5. **技巧预言**：提供游戏技巧和策略建议
6. **结局预言**：总结玩家的游戏表现

### 文本风格

预言文本采用以下风格特点：

- **神谕语调**：模仿古希腊神谕的神秘、模糊语言
- **双关语**：巧妙融入游戏机制和现代元素
- **韵律感**：保持一定的节奏和韵律，增强记忆性
- **简洁有力**：每条预言保持在50字以内，直击要点
- **引人思考**：留有解读空间，鼓励玩家思考

### 预言示例

以下是各类预言的示例：

#### 引导预言

```
"来自奥林匹斯的建造者，你的旅程始于这神圣的基石。堆叠你的命运，直至触碰云端。"

```

```
"注意，凡人！高处的风更加无情，接下来的考验将挑战你的沉着与技巧。"

```

## 视觉与音效设计

### 视觉效果

预言系统的视觉设计遵循以下规范：

- **文本容器**：半透明的云雾效果，边缘模糊
- **文字特效**：金色轮廓，淡蓝色发光效果
- **出现动画**：文字从模糊到清晰的淡入效果
- **消失动画**：文字向上飘散消失
- **背景效果**：预言出现时背景轻微变暗，增强可读性

#### 特殊预言视觉差异

| 预言类型 | 文字颜色 | 特殊效果 |
|---------|---------|---------|
| 普通预言 | 白色 | 标准淡入淡出 |
| 完美预言 | 金色 | 光芒四射，粒子效果 |
| 挑战预言 | 蓝色 | 闪烁，光波效果 |
| 结局预言 | 渐变色 | 卷轴展开，华丽框架 |

### 音效设计

预言系统的音效设计包含以下元素：

- **预言出现音效**：神秘的弦乐和风声混合
- **文字显现音效**：轻微的水晶音效随文字显现
- **完美预言音效**：庄严的合唱团短音
- **预言消失音效**：淡出的风铃声

### 性能优化

为确保预言系统不影响游戏性能：

- 预言文本在游戏初始化时全部加载到内存
- 使用CSS动画而非JavaScript动画处理视觉效果
- 限制同时显示的预言数量为1条
- 使用预加载技术处理音效资源

### 本地化支持

预言系统支持多语言，通过以下机制实现：

- 所有预言文本存储在语言特定的JSON文件中
- 动态加载对应语言的文本资源
- 保持文本显示区域大小一致，适应不同语言文本长度

## 测试与优化

### 测试计划

Oracle系统的测试应包括以下方面：

1. **功能测试**：验证所有触发机制是否正常工作
2. **性能测试**：确保预言显示不影响游戏帧率
3. **用户体验测试**：评估预言的可读性和时机
4. **文本质量测试**：检查预言文本的语法、拼写和风格一致性

### 优化指标

系统应满足以下性能指标：

- 预言显示不引起帧率下降超过5%
- 预言文本加载时间不超过500ms
- 预言触发到显示的延迟不超过100ms
- 预言文本应在1秒内完全淡入

## 未来扩展

Oracle系统设计为可扩展架构，未来可添加以下功能：

- **预言选择系统**：提供多条预言供玩家选择，影响游戏后续发展
- **互动预言**：玩家可以与预言互动，如点击特定词汇获取提示
- **预言收集图鉴**：玩家可以收集发现的预言，鼓励多次游戏
- **随时间变化**：根据真实时间（日/夜，节日等）提供特殊预言
